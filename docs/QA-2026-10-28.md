The QA client needs no Screen Recording or Accessibility grant merely to display remote frames. Only the host captures and initializes approved input. Starting a listener does not imply successful screen capture: the host exposes actual sharing state, and capture requires macOS authorization.

Early stale permission records produced wallpaper-only frames. Those were not counted as full desktop validation. After stable development signing, targeted EasyControl permission resets and fresh user grants, full desktop content was observed. The capture backend now refuses capture when macOS preflight reports access denied, instead of treating wallpaper-only output as authorized capture. No OS security controls were bypassed.

Screen contents and session passwords are intentionally excluded from this report and saved evidence.

## Confirmed defects resolved

1. Restore visible host approve/revoke/disconnect controls and actual macOS permission guidance.
2. Bind the listener before readiness, report bind errors, and preserve the listener after failed authentication.
3. Serialize lifecycle operations, cancel pending connections, and guard old-session events from clearing a newer session.
4. Enforce session identity for frames, input and monitor commands; keep disconnect available during queued commands.
5. Preserve bounded event forwarding through lag; clear viewer buffers and session state on disconnect.
6. Default each desktop host session to view-only; apply host permission changes only after backend success.
7. Bound frame packets and decompression; decode padded RGBA rows; count unread replacements accurately.
8. Keep one outstanding frame request, coalesce mouse movement, bound wheel requests, and skip missed capture ticks.
9. Correct Retina logical-coordinate mapping, button/wheel units, unsupported keys and held-input cleanup.
10. Make Retina scaling macOS-specific and use actual primary-monitor metadata.
11. Report actual capture health, retry capture failures with bounded cadence, and reject capture without an OS grant.
12. Permit Tauri internal binary IPC in production/QA CSP without adding a public frame endpoint.
13. Put the active viewer first and hide connection forms while viewing.
14. Fix Enter activating password reveal, light-theme danger contrast and permission-panel spacing.
15. Prevent bad relay tokens from evicting waiting registrations; cap peers/registrations and guard stale cleanup.
16. Sign complete macOS bundles and stabilize local test signing identity.
17. Standardize CLI default port to 5899 and avoid logging clipboard contents.

## Release foundations and remaining gates

MIT license selected by the owner is included and declared in Cargo metadata. README build/security/QA guidance and a macOS CI workflow were added. Protocol v5 is unchanged.

Before public release:

- Perform controlled real input, focus/key release and revocation-denial tests, preferably between two authorized machines.
- Manually test fullscreen in an active window and test a real second monitor.
- Exercise physical-network interruption, host shutdown, extended reconnect/soak and resource stability.
- Measure total application resource usage, input responsiveness and end-to-end latency.
- Complete Developer ID signing/notarization and clean-machine install/Gatekeeper checks.
- Validate Windows/Linux separately before claiming support, and run independent security review.

The real macOS view-only flow is demonstrated. EasyControl is not yet certified production-ready; the outstanding input and distribution gates remain.
